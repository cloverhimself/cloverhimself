* REST API design
* Authentication and user sessions
* Role-based access control
* Database relationships
* PostgreSQL queries and schema design
* Webhooks and payment verification
* Idempotency and duplicate transaction prevention
* File uploads and storage
* Error handling and edge cases
* Server-side validation
* Deployment and environment variables

* How databases connect to applications
* How caching improves performance
* How queues and background jobs work
* How APIs can be structured for external platforms

## How I Learn

```txt
Pick a concept
Understand the basic idea
Build something small with it
Break it
Debug it
Ask better questions
Refactor it
Document what I learned
Repeat
```

I believe learning becomes real when you can explain what broke, why it broke, and how you fixed it.

## My Engineering Mindset

I’m learning to move from:

```txt
"It works"
```

to:

```txt
"It works properly, securely, and can be maintained."
```

That means I care about:

* Clean logic
* Secure access control
* Good database structure
* Clear API responses
* Useful error messages
* Testing important flows
* Writing code that future me can understand
